# Data Diff Explorer

Compare two CSV datasets in the browser and focus on meaningful row-level changes.

## What it does

- Selects a key column.
- Finds added, removed and changed rows.
- Compares individual field values.
- Shows a compact change summary.

## Usage

Load or paste the **before** and **after** CSV datasets, select a key column and run the comparison.

## Privacy

All parsing and comparison happen locally in your browser.
